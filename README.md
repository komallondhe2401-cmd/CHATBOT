# Chatbot
-Overview
This project presents an AI-Powered Retrieval-Augmented Generation (RAG) Chatbot that integrates LangChain, Google Gemini, and vector-based document retrieval to deliver accurate, context-aware, and reliable responses. The chatbot supports both Desktop (Streamlit UI) and Telegram platforms, enabling seamless and intelligent interaction across devices.

-Project Objective
1.Accurate Query Answering
Answers user queries precisely using uploaded PDF documents as the knowledge base.

2.Source-Based Reliability
Uses document retrieval to reduce hallucinations and ensure grounded responses.

3.Multi-Platform Accessibility
Accessible via Desktop UI and Telegram mobile application.

-Conclusion
This project demonstrates a real-world, document-grounded AI chatbot leveraging modern tools like LangChain, FAISS, and Gemini. The dual-platform deployment ensures accessibility, while RAG architecture guarantees factual and reliable responses, making it suitable for academic, research, and enterprise use cases
